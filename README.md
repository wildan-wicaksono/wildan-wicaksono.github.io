# Wildan's Homepage

Repositori sumber untuk situs pribadi **Wildan Bagus Wicaksono**—mahasiswa Matematika Universitas Brawijaya, pengajar olimpiade matematika, dan penulis *The Art of Olympiad Geometry*.

**[Kunjungi wildan-wicaksono.github.io](https://wildan-wicaksono.github.io/)**

## Isi situs

- [Beranda](https://wildan-wicaksono.github.io/) — profil dan perjalanan saya di bidang matematika.
- [Teaching](https://wildan-wicaksono.github.io/teaching/) — pengalaman serta materi pengajaran olimpiade.
- [Projects](https://wildan-wicaksono.github.io/projects/) — buku dan proyek matematika.
- [Blog](https://wildan-wicaksono.github.io/year-archive/) — tulisan, catatan, dan cerita di balik karya.
- [CV](https://wildan-wicaksono.github.io/cv/) — pendidikan, pengalaman, dan prestasi.

## Proyek utama

[**The Art of Olympiad Geometry**](https://wildan-wicaksono.github.io/portfolio/the-art-of-olympiad-geometry/) adalah buku geometri olimpiade berbahasa Indonesia yang disusun secara bertahap, dari konsep dasar menuju pemecahan masalah.

Cerita mengenai proses lahir dan penulisan buku tersebut dapat dibaca dalam artikel [**Cerita di Balik *The Art of Olympiad Geometry***](https://wildan-wicaksono.github.io/posts/2026/09/cerita-di-balik-the-art-of-olympiad-geometry/).

## Teknologi

Situs ini dibangun menggunakan:

- [Jekyll](https://jekyllrb.com/) dan [GitHub Pages](https://pages.github.com/);
- [Academic Pages](https://academicpages.github.io/), yang dikembangkan dari tema [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/); dan
- [Giscus](https://giscus.app/) dengan GitHub Discussions untuk kolom komentar.

## Menjalankan secara lokal

Pastikan Ruby dan Bundler sudah terpasang, kemudian jalankan:

```bash
git clone https://github.com/wildan-wicaksono/wildan-wicaksono.github.io.git
cd wildan-wicaksono.github.io
bundle install
bundle exec jekyll serve -l -H localhost
```

Situs lokal dapat dibuka melalui [http://localhost:4000](http://localhost:4000).
